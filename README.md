# אחד

תרגול חשבון לכיתות א׳–ב׳, שמשלים את מה שנלמד בכיתה. אחות של [אלף](https://github.com/net13200/Aleph), ונפתחת עם אנימציית הפתיחה של SugiGames.
("אחד" הוא שם עבודה.)

אתר סטטי (PWA), בלי שלב בנייה. עובד בלי אינטרנט אחרי הטעינה הראשונה, וכל המידע נשמר על המכשיר בלבד.

## הרצה

```sh
npx http-server -c-1 .
```

ואז לפתוח את הכתובת בטלפון ("הוספה למסך הבית" באייפון / "התקנת אפליקציה" בכרום באנדרואיד).
צריך שרת (לא `file://`) כדי שמצב לא־מקוון יעבוד.

## מה יש בגרסה הראשונה

- **שלושה נושאים**: חיבור (8 רמות), חיסור (8 רמות), חברים של 10 ופירוק (6 רמות). כל הרמות מוגדרות בטבלה אחת ב־`js/data.js`.
- **רמת פתיחה גבוהה מעט** לכיתה א׳: חיבור וחיסור מתחילים ברמה 3 (עד 20 בלי מעבר עשרת, עם מספר חסר בחלק מהתרגילים), וחברים של 10 ברמה 2 (בלי מסגרת עשר). כיתה ב׳ מתחילה בעשרות שלמות.
- **צורת תשובה**: בחירה מבין 3 (מסיחים קרובים: ±1, או טעות נפוצה כמו חיבור במקום חיסור), או הקלדה במקלדת מספרים גדולה.
- **עזרה ויזואלית** (💡): מסגרות עשר עם נקודות עד 20, מקלות עשרות וקוביות יחידות מעל 20 (כולל פריטת עשרת בחיסור), ותמונות ברמה 1.
- **משוב בלי לחץ**: בטעות ראשונה — צליל רך, העזרה מופיעה ו"בּוֹא נִבְדֹּק יַחַד". בשנייה — הדרך לפתרון צעד אחר צעד (8 + 5 = 8 + 2 + 3 = 10 + 3 = 13), והתרגיל חוזר מאוחר יותר באותו ששן.
- **ששן**: 10 תרגילים. רובם מהרמה הנוכחית, כ־20% חזרה מהרמה הקודמת, ועובדות שטעו בהן חוזרות מוקדם. עובדה נחשבת נלמדה אחרי 3 תשובות נכונות ברצף בשני ששנים שונים.
- **מדבקות**: מדבקה לכל ששן שהסתיים, ומדבקת זהב לכל רמה שהילד עבר.
- **אזור הורים** (לחיצה ארוכה על המנעול + תרגיל כפל דו־ספרתי):
  - כיתה, ולכל נושא: מתג פעיל/כבוי, הרמה עם "הַעֲלֵה רָמָה" / "הוֹרֵד רָמָה", תיאור הרמה ודוגמה.
  - התקדמות אוטומטית: הצעה לעלות רמה אחרי 8 מתוך 10 בשני ששנים (ולרדת אחרי הרבה טעויות). הרמה לא משתנה בלי אישור.
  - תרגילים השבוע, אחוז הצלחה לפי נושא, ועובדות שמתקשים בהן עם אפשרות לתרגל אותן בששן הבא.
  - שם, פנייה (בן/בת), צורת תשובה, מהירות קול, בדיקת קול לכל המשפטים והמספרים.
  - כמה ילדים (בחירה בין הפרופילים במסך הבית), גיבוי ושחזור לקובץ, מחיקת נתונים.

## קול

כל הנחיה נשמעת בקול העברי של המכשיר (Web Speech API, קול לוקלי אם יש). אין הקלטות סינתטיות.
לכל משפט מפתח קבוע (`p.howMuch`, `num.7`, `op.plus`); כדי להחליף משפט בהקלטה בעתיד מוסיפים את המפתח ל־`RECORDINGS` ב־`js/data.js` ושמים את הקובץ ב־`audio/`.
מספרים נקראים בצורת הנקבה המופשטת, עם ניקוד (`js/numbers.js`): "שָׁלוֹשׁ וְעוֹד אַרְבַּע", "שְׁלוֹשׁ מֵאוֹת עֶשְׂרִים וְחָמֵשׁ".
פעולות: "וְעוֹד", "פָּחוֹת", "שָׁוֶה".

## מבנה

| קובץ | תפקיד |
| --- | --- |
| `js/data.js` | טבלת הנושאים והרמות, המשפטים, המדבקות |
| `js/numbers.js` | מספר (0–1000) למילים בעברית עם ניקוד |
| `js/gen.js` | מחולל התרגילים: תרגיל לפי רמה, מסיחים, הדרך לפתרון, העזרה הוויזואלית |
| `js/store.js` | פרופילים, התקדמות, הצעות רמה ותכנון ששן (`localStorage`) |
| `js/audio.js` | קול המכשיר וצלילי משוב (WebAudio) |
| `js/app.js` | המסכים, התרגילים ואזור ההורים |
| `js/splash.js` | אנימציית הפתיחה של SugiGames |
| `sw.js` | עבודה בלי רשת. **להעלות את `CACHE` בכל שחרור** |

## בדיקות

```sh
node --test tests/*.test.js   # בדיקות יחידה: מספרים במילים, מחולל התרגילים, התקדמות
node tests/e2e.js              # דפדפן בגודל iPhone 12 Pro, צילומי מסך ב־tests/shots/
node tests/install-check.js    # Chrome: האם האפליקציה ניתנת להתקנה
```

## פריסה

GitHub Pages דרך GitHub Actions, בכל push ל־`main`. פעם אחת, בהגדרות הריפו: Pages ← Source = "GitHub Actions".
ה־workflow מעתיק רשימת תיקיות ל־`_site/` — כל תיקייה חדשה צריכה להיכנס לרשימה ב־`.github/workflows/pages.yml`.
